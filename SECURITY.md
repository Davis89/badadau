# Security Policy

BADADAU is currently pre-alpha. There are no supported stable release branches yet.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for a security-sensitive vulnerability.

Until private vulnerability reporting is formally enabled for the repository, contact the repository maintainer privately through the GitHub account associated with this project and include:

- Affected revision or version.
- Reproduction steps.
- Expected impact.
- Any proof-of-concept material needed to understand the issue.

Please avoid including unrelated personal data, credentials, private audio projects, or proprietary plugin content in reports.

## Scope

Security-relevant areas include plugin scanning/hosting, project/session parsing, network/control-surface interfaces, file import/export, scripting, and platform integration.
